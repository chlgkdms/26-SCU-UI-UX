사용자의 영어 수준을 분석하여 개인화된 학습 기능을 제공함

EngAI는 사용자의 영어 수준을 분석하여 개인화된 학습 기능을 제공합니다.

단어장, 문법 학습, 회화 연습 등 다양한 학습 기능을 통해 사용자가 효과적으로 영어를 학습할 수 있도록 지원합니다.

학습 기능

  • 단어장

    사용자의 수준에 맞는 다양한 단어장을 제공합니다.

  • 문법 학습

    사용자의 수준에 맞는 문법 학습 자료를 제공합니다.

  • 회화 연습

    AI와의 대화를 통해 실제 회화 능력을 향상시킬 수 있습니다.

이용 방법

  1. 회원가입 후 로그인합니다.
  2. 영어 수준 테스트를 진행합니다.
  3. 개인화된 학습 경로를 확인합니다.
  4. 각각의 학습 기능을 사용하여 학습을 시작합니다.
